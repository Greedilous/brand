# BE GREEDILOUS

그리디어스의 반복과 화려함을 연결한 브랜드 코어 리브랜딩 제안서입니다.

공개 사이트: https://greedilous.github.io/brand/be-greedilous/

## 구성

브랜드의 이름과 기존 자산, 반복의 의미, BE GREEDILOUS 슬로건, 세 겹의 G 패턴, 의류·패키지·캠페인 적용 시안을 9개 장으로 소개합니다.

## 편집과 게시

- 본문: index.html
- 화면 구성: styles.css, brand-refresh.css
- 스크롤 모션, 발표 이동, 패턴 조절, 탭: app.js
- 이미지·폰트·패턴: assets/

이 저장소의 기존 GitHub Pages 게시 설정을 사용합니다. GitHub Desktop에서 main 브랜치에 변경을 커밋하고 Push origin을 누르면 페이지가 갱신됩니다.

HTML·CSS·JavaScript만 사용하는 정적 사이트로, 빌드나 별도 서버가 필요하지 않습니다. 로컬에서는 이 폴더를 정적 웹 서버로 열어 확인할 수 있습니다.

## 출처와 시안

공식 제품 사진과 참고 링크는 페이지 하단 및 asset-sources.json에 명시되어 있습니다. ECHO G는 신규 그래픽 시안이며, 의류·패키지 이미지는 AI로 제작한 적용 시안입니다. 실제 출시 제품이나 확정된 공식 로고를 의미하지 않습니다. Pretendard의 라이선스는 assets/Pretendard-LICENSE.txt에 포함되어 있습니다.
