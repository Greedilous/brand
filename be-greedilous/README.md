# BE GREEDILOUS

그리디어스의 화려한 자기표현을 반복되는 시그니처로 연결한 리브랜딩 제안서.

공개 사이트: https://greedilous.github.io/brand/be-greedilous/

## 구성

1. BE GREEDILOUS — 거듭 화려하게, 더욱 나답게
2. 방향 — 이어갈 화려함, 더할 반복의 원리
3. 브랜드 코어 — 나만의 화려함을 거듭 표현하라
4. 시그니처 — G의 표현·반복·각인
5. 패턴 — 같은 형태의 색과 크기 변주
6. 적용 — 캠페인·라벨·패키지
7. 다음 단계 — 세 접점에서 먼저 적용

## 편집과 게시

본문은 index.html, 화면 구성은 styles.css, 모션·발표 이동·패턴 조절은 app.js에서 수정합니다. 별도의 빌드 없이 HTML·CSS·JavaScript로 동작합니다.

기존 GitHub Pages 설정을 사용합니다. GitHub Desktop에서 main에 커밋하고 Push origin을 누르면 페이지가 갱신됩니다. 기존 저장소의 루트 홈페이지와 영상은 유지합니다.

## 발표와 접근성

INDEX와 이전·다음 버튼, 좌우 방향키 및 Page Up/Down으로 장을 이동합니다. 발표 모드는 전체 화면을 지원합니다. 모션 설정은 동작 줄이기 환경설정을 반영합니다. JavaScript가 없어도 본문과 모든 적용 시안을 읽을 수 있습니다.

## 디자인과 출처

모델·룩북 사진을 제거하고 타이포그래피, SVG 시그니처, 패턴 및 CSS 적용 시안으로 구성했습니다. Plus X의 SLL 사례는 서사와 발표 구성만 참고했으며 자산을 복제하지 않았습니다. 로고·패턴·적용 그래픽은 리브랜딩 검토안입니다. 본문 참고 링크는 페이지 하단에, 자산 출처는 asset-sources.json에 있습니다. Pretendard의 라이선스는 assets/Pretendard-LICENSE.txt에 있습니다.
